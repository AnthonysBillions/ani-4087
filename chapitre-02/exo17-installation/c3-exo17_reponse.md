# Exercice 17 — Installation sur un appareil

**Étudiant :** Pee Steve Anthony  
**Matricule :** 25P812  
**Sprint :** 2  
**Chapitre :** 3 — Construction et déploiement avec Jenga


## Énoncé

Installer le paquet sur un appareil et lancer le programme. Rendre une photographie de l'écran. En cas d'échec, rendre le message exact.

## Commande

```text
jenga deploy
```

### Rendu simulé en cas de réussite

```text
Deploying MaSalle.apk
Target device: emulator-5554
Installing package...
Installation succeeded.
Launching application...
Application started.
```

## Photographie

La photographie réelle doit être ajoutée au dossier de rendu lorsqu'elle est disponible. Elle ne peut pas être produite honnêtement à partir du seul document du cours, car elle doit montrer l'écran d'un appareil réel ou d'un émulateur.

## Si l'installation échoue

Il faut conserver le message exact, par exemple :

```text
error: no device available
```

ou le message réellement affiché par Jenga.

La sortie ci-dessus est simulée et ne doit pas être présentée comme une installation réellement effectuée.
